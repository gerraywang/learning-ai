# Contract: 保存形式（localStorage）

**Date**: 2026-11-22 | 関連: FR-012 / FR-013 / FR-014、[data-model.md](../data-model.md)

## キー

`sdd-speckit-todo`（1 つだけ）

## 値（JSON 文字列）

```json
{
  "version": 1,
  "todos": [
    { "id": "0b6f…", "title": "牛乳を買う", "done": false, "due": "2026-11-30" },
    { "id": "7c1e…", "title": "本を返す", "done": true, "due": null }
  ]
}
```

- `todos` の並び順が表示順（追加した順）。
- 各要素の項目と制約は [data-model.md](../data-model.md) の Todo のとおり。

## 読み込み（`load(storage)`）

| 状況 | 結果 |
|---|---|
| キーがない | 空の一覧。お知らせなし |
| 正しい形式（`version === 1` で `todos` が配列、各要素が Todo の制約を満たす） | その一覧 |
| JSON として読めない、`version` が違う、`todos` が配列でない、要素が制約を満たさない | 空の一覧 ＋「保存されたデータを読み込めませんでした」。保存されている値は消さない |
| `storage` へのアクセスが例外を投げる | 空の一覧 ＋「この端末に保存できません。閉じると内容は消えます」 |

## 保存（`save(storage, todos)`）

- 追加・完了の切り替え・削除のたびに、全体を 1 回書き直す。
- `setItem` が例外を投げたら、画面の状態はそのままにして「保存できませんでした」を表示する。
- 戻り値で成功／失敗を返し、例外を外に出さない（app.js がメッセージを決める）。

## 端末の外への送信

なし。ネットワーク通信を行うコードを含めない（FR-013 / SC-005）。
