# Data Model: やることの文言を後から編集する

**Date**: 2026-11-22 | **Plan**: [plan.md](./plan.md) | **Spec**: [spec.md](./spec.md)

001 の [data-model.md](../001-todo-app/data-model.md) に対する差分だけを書く。

## Todo（やること）— 項目は変わらない

| 項目 | 本機能での扱い | 根拠 |
|---|---|---|
| `id` | 変えない。どのやることを編集するかを決める | FR-007、Edge Cases（同じ文言が複数） |
| `title` | **編集で変わる唯一の項目**。検証ルールは 001 と同じ（前後の空白を除いて 1〜200 文字） | FR-003 / FR-005 / FR-006 |
| `done` | 変えない | FR-007 |
| `due` | 変えない | FR-007 |

- 順番（配列の並び）も変えない（FR-007）。
- 保存データの形式（[001 contracts/storage.md](../001-todo-app/contracts/storage.md)）は変わらない。
  `version` も 1 のまま。

### 検証ルール（確定するとき）

| ルール | 違反したとき | 根拠 |
|---|---|---|
| `draft.trim()` の長さが 0 | 確定しない。編集中のまま入力を残し「やることを入力してください」 | FR-006、US3-1 / US3-2 |
| `draft.trim()` の長さが 200 を超える | 確定しない。編集中のまま入力を残し「200 文字以内で入力してください」 | FR-006、US3-3 |
| 前後の空白は除いて新しい `title` にする | — | FR-005、US1-7 |
| 元と同じ文言 | エラーにしない。そのまま確定扱い | Edge Cases |

### 編集の状態の変化

```text
                    「編集」を押す（draft = 今の文言）
   ┌──────────┐ ───────────────────────────────▶ ┌────────────────┐
   │ editing  │                                   │ editing =      │
   │ = null   │ ◀─────────────────────────────── │ { id, draft }  │──┐ 決まりに合わない
   └──────────┘  確定（title を変えて保存）        └────────────────┘  │ 文言で確定
         ▲       取り消し（「取り消し」・Esc）            ▲            │（draft = 入力、
         │       ほかの操作・入力欄の外のクリック        └────────────┘   お知らせを出す）
         │       （取り消しと同じ。保存しない）
         │
         └── 別の行の「編集」を押すと、前の編集は取り消し、新しい行で editing を作る（FR-010）
```

- 「ほかの操作」= 完了の切り替え・削除・絞り込みの切り替え・正しい文言での追加（FR-004、Clarifications）。
- ページを再読み込みすると `editing` は `null` から始まる（保存しないため。spec の Assumptions）。
