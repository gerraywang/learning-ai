# Contract: 画面（UI）— 編集の追加分

**Date**: 2026-11-22 | 関連: [spec.md](../spec.md) の US1〜US3、FR-001〜FR-012

001 の [contracts/ui.md](../../001-todo-app/contracts/ui.md) に足す約束。001 の約束は変えない。
テスト（`tests/ui/edit.test.js`）は、ここに書いたラベル・役割・文言で要素を探す。

## 一覧の 1 行（通常のとき）に足す部品

| 部品 | 内容 | 関連 |
|---|---|---|
| 編集ボタン | 「編集」（読み上げ用の名前は「<文言> を編集」）。削除ボタンの前に置く | FR-001 |

- 削除ボタンには `remove` クラス、編集ボタンには `edit` クラスを付ける（行の中で区別するため）。

## 一覧の 1 行（編集中のとき）

編集中の行（`<li>` に `editing` クラス）は、完了チェック・文言・編集ボタン・削除ボタンの代わりに
次のフォームを出す。期限と期限切れの印は通常のときと同じく表示する。

| 部品 | 内容 | 関連 |
|---|---|---|
| 編集フォーム | `<form class="edit-form">` | FR-012 |
| 文言の入力欄 | `<input type="text">`、読み上げ用の名前「やることの文言」。開いたときは今の文言が入り、フォーカスがある | FR-002 |
| 確定ボタン | `<button type="submit">`「確定」 | FR-003 |
| 取り消しボタン | `<button type="button">`「取り消し」 | FR-004 |

- 同時に編集中になる行は 1 つだけ（FR-010）。

## 操作と結果

| 操作 | 結果 |
|---|---|
| 「編集」 | その行が編集中になる。入力欄に今の文言、フォーカスは入力欄。ほかの行が編集中なら、その編集は取り消す。お知らせを消す（保存先が使えないお知らせは残す） |
| 正しい文言で「確定」（入力欄で Enter でも可） | 前後の空白を除いた文言に変えて保存。行は通常に戻り、フォーカスはその行の「編集」。期限・完了・順番は変わらない |
| 空・空白だけで「確定」 | 変えない。編集中のまま入力を残す。お知らせ「やることを入力してください」 |
| 201 文字以上で「確定」 | 変えない。編集中のまま入力を残す。お知らせ「200 文字以内で入力してください」 |
| 「取り消し」（入力欄で Esc でも可。日本語の変換中の Esc は除く） | 元の文言のまま通常に戻る。保存しない。フォーカスはその行の「編集」。お知らせを消す（保存先が使えないお知らせは残す） |
| 編集中に、完了の切り替え・削除・絞り込み・正しい文言での追加 | 編集は取り消し（保存しない）、その操作は通常どおり行う |
| 編集中に、編集中の行の外をクリック | 編集を取り消す（保存しない）。お知らせを消す（保存先が使えないお知らせは残す） |

- 「お知らせを消す」は、確定できなかったときの理由（「やることを入力してください」など）が、取り消した後に
  残らないようにするため（implement の見直しで追加、2026-11-22）。
| 確定したときに保存に失敗 | 表示は新しい文言。お知らせ「保存できませんでした」（001 と同じ） |

## お知らせの文言

001 と同じ文言を使う。新しい文言は足さない。
