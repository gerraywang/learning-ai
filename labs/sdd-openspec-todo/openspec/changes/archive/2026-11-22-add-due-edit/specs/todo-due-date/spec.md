# Spec Delta

## MODIFIED Requirements

### Requirement: 追加するときに期限を付ける
システムは、やることを追加するときに、日付の入力欄（「期限（任意）」）で期限を付けられるようにする（SHALL）。期限を入れなければ、期限なしのやることとして追加する。

#### Scenario: 期限を指定して追加する
- **WHEN** 期限に 2026-12-01 を指定して追加する
- **THEN** そのやることの行に「期限: 2026-12-01」と表示される

#### Scenario: 期限を指定せずに追加する
- **WHEN** 期限を空のまま追加する
- **THEN** 期限なしで追加され、行に期限は表示されない

## ADDED Requirements

### Requirement: あとから期限を変える・外す
システムは、追加したあとのやることの期限を、編集で変えたり、外して期限なしに戻したり、期限なしのやることに付けたりできるようにする（SHALL）。期限切れかどうかは、確定した新しい期限で判断する。

#### Scenario: 期限を変える
- **GIVEN** 期限が 2026-12-01 のやることがある
- **WHEN** 編集で期限を 2026-12-24 にして確定する
- **THEN** 行に「期限: 2026-12-24」と表示される

#### Scenario: 期限を外す
- **GIVEN** 期限が 2026-12-01 のやることがある
- **WHEN** 編集で日付欄を空にして確定する
- **THEN** 期限なしになり、行に期限は表示されない

#### Scenario: 期限なしのやることに期限を付ける
- **GIVEN** 期限なしのやることがある
- **WHEN** 編集で期限を 2026-12-01 にして確定する
- **THEN** 行に「期限: 2026-12-01」と表示される

#### Scenario: 期限を先に延ばすと期限切れでなくなる
- **GIVEN** 今日が 2026-11-22 で、期限が 2026-11-21 の未完了のやること（期限切れ）がある
- **WHEN** 編集で期限を 2026-11-30 にして確定する
- **THEN** 「期限切れ」の表示が消える

#### Scenario: 期限を過去にすると期限切れになる
- **GIVEN** 今日が 2026-11-22 で、期限なしの未完了のやることがある
- **WHEN** 編集で期限を 2026-11-01 にして確定する
- **THEN** 「期限切れ」と表示される
