## はじめに
ブラウザで使う 1 人用の TODO リストアプリ。利用者は、やること（TODO）を内容と期限つきで追加し、
完了にしたり、未完了に戻したり、削除したり、すべて・未完了・完了で表示を切り替えたりできる。
データは利用者の端末のブラウザ内に保存し、保存できる環境であれば、ページの再読み込みやブラウザを閉じても消えない。

## 要件 1: TODO を追加する

**ユーザーストーリー:** 利用者として、TODO の内容と期限を入力して一覧に追加したい。
やることと締め切りを忘れないため。

### 受け入れ条件
1. WHEN 利用者が内容と期限を入力して追加する THE SYSTEM SHALL その TODO を未完了として一覧に追加する
2. WHEN 利用者が内容を入力せずに追加しようとする THE SYSTEM SHALL TODO を追加せず、内容が必要であることを示す。
   内容が空白だけの場合も、入力なしとみなす（おまかせで決定）
3. WHEN 利用者が期限を入力せずに追加しようとする THE SYSTEM SHALL TODO を追加せず、期限が必要であることを示す
4. WHEN 利用者が 200 文字を超える内容で追加しようとする THE SYSTEM SHALL TODO を追加せず、200 文字以内であることを示す。
   文字数は前後の空白を除いて数える（おまかせで決定）
5. WHEN 利用者が TODO を追加する THE SYSTEM SHALL 内容の前後の空白を取り除いて保存する（おまかせで決定）
6. WHEN TODO を追加できた THE SYSTEM SHALL 内容と期限の入力欄を空に戻す（おまかせで決定）
7. WHEN TODO を追加できなかった THE SYSTEM SHALL 入力した内容と期限をそのまま残す（おまかせで決定）
8. WHEN 追加しようとした入力が 1.2・1.3・1.4・2.1 の複数に当てはまる THE SYSTEM SHALL 当てはまるものをすべて示す
9. WHEN 1.2・1.3・1.4・2.1 を示したあとで、利用者が TODO を追加できた THE SYSTEM SHALL それらの表示を消す
10. THE SYSTEM SHALL 内容と期限が同じ TODO でも、別々の TODO として追加できるようにする（おまかせで決定）
11. THE SYSTEM SHALL TODO を追加した順（古いものが上）に表示し、完了・未完了の切り替えや再読み込みでは順番を変えない（おまかせで決定）
12. THE SYSTEM SHALL 内容に記号や HTML の文字（`<` `>` など）が含まれていても、入力された文字のとおりに表示する（おまかせで決定）

## 要件 2: 期限は今日以降だけ

**ユーザーストーリー:** 利用者として、期限には今日以降の日付だけを入れたい。
過去の日付を誤って入れないため。

### 受け入れ条件
1. WHEN 利用者が今日より前の日付を期限として追加しようとする THE SYSTEM SHALL TODO を追加せず、
   期限は今日以降であることを示す。どのような方法で入力された日付でも同じに扱う
2. THE SYSTEM SHALL 期限を日付だけで扱い（時刻は持たない）、「今日」を利用者の端末の日付（端末のタイムゾーン）で判断する（おまかせで決定）
3. WHILE 未完了の TODO の期限が今日より前である THE SYSTEM SHALL その TODO を期限切れと分かるように表示する（おまかせで決定）
4. WHILE 期限が今日より前の TODO が完了している THE SYSTEM SHALL 期限切れの表示をしない（おまかせで決定）
5. THE SYSTEM SHALL 期限切れかどうかを、アプリを開いたときの「今日」で判断する。
   開いたまま日付が変わっても、再読み込みするまで表示は変えない

## 要件 3: TODO を完了にする・未完了に戻す

**ユーザーストーリー:** 利用者として、終わった TODO を完了にしたい。何が残っているかを分かるようにするため。

### 受け入れ条件
1. WHEN 利用者が未完了の TODO を完了にする THE SYSTEM SHALL その TODO を完了として表示し、未完了と見分けられるようにする
2. WHEN 利用者が完了の TODO を未完了に戻す THE SYSTEM SHALL その TODO を未完了として表示する

## 要件 4: TODO を削除する

**ユーザーストーリー:** 利用者として、いらなくなった TODO を削除したい。一覧を整理するため。

### 受け入れ条件
1. WHEN 利用者が TODO を削除する THE SYSTEM SHALL 確認せずに、その TODO だけを一覧から取り除く。
   完了・未完了のどちらでも同じに扱い、内容と期限が同じ TODO が他にあっても、選んだ 1 件だけを取り除く（おまかせで決定）

## 要件 5: すべて・未完了・完了で表示を切り替える

**ユーザーストーリー:** 利用者として、すべて・未完了・完了で一覧を切り替えたい。残っているものだけ、終わったものだけを見るため。

### 受け入れ条件
1. WHEN 利用者が「すべて」を選ぶ THE SYSTEM SHALL 完了・未完了を問わずすべての TODO を表示する
2. WHEN 利用者が「未完了」を選ぶ THE SYSTEM SHALL 未完了の TODO だけを表示する
3. WHEN 利用者が「完了」を選ぶ THE SYSTEM SHALL 完了の TODO だけを表示する
4. WHEN 選んでいる表示に合わなくなる操作をした（「未完了」を選んでいるときに完了にした、「完了」を選んでいるときに追加した など）
   THE SYSTEM SHALL その TODO をすぐ表示から外す
5. WHEN 利用者がアプリを開く（再読み込みを含む） THE SYSTEM SHALL 「すべて」を選んだ状態で表示する。選んだ表示は保存しない（おまかせで決定）
6. WHILE TODO が 1 件もない THE SYSTEM SHALL TODO がないことを示す（おまかせで決定）
7. WHILE TODO はあるが、選んだ表示に合う TODO が 0 件 THE SYSTEM SHALL 該当する TODO がないことを、6 とは区別して示す（おまかせで決定）

## 要件 6: データを保存する

**ユーザーストーリー:** 利用者として、ページを再読み込みしたりブラウザを閉じたりしても TODO が消えないようにしたい。入れ直さずに済むため。

### 受け入れ条件
1. WHEN 利用者が TODO を追加する・完了にする・未完了に戻す・削除する THE SYSTEM SHALL その操作のたびに、すぐ結果を利用者の端末のブラウザ内に保存する（おまかせで決定）
2. WHEN 利用者がページを再読み込みする THE SYSTEM SHALL 保存した TODO（内容・期限・完了かどうか・並び順）を元どおりに表示する
3. WHEN 利用者がブラウザやタブを閉じて、同じ端末・同じブラウザで開き直す THE SYSTEM SHALL 保存した TODO を元どおりに表示する
4. WHEN 保存できなかった（ブラウザの設定で禁止・容量不足など） THE SYSTEM SHALL そのことを利用者に知らせ、開いている間は操作を続けられるようにする。
   知らせるのは同じ原因につき 1 回とし、閉じると内容が消えることも伝える（おまかせで決定）
5. WHEN 保存したデータが読み込めなかった（壊れている・読み出しが禁止されている など） THE SYSTEM SHALL 空の一覧で始め、
   読み込めなかったことを利用者に知らせる。壊れたデータは、利用者が次に操作して保存するまで消さない（おまかせで決定）

## 要件 7: 非機能（おまかせで決定）

### 受け入れ条件
1. THE SYSTEM SHALL パソコンの最新のブラウザ（Chrome / Edge / Firefox / Safari）で動く
2. THE SYSTEM SHALL マウスを使わず、キーボードだけですべての操作ができる
3. THE SYSTEM SHALL TODO のデータを端末の外（サーバーや外部サービス）へ送らない

## やらないこと（おまかせで決定）
- TODO の内容・期限の編集（必要なら削除して追加し直す）
- 削除の取り消し、一括削除
- 並べ替え、検索、カテゴリ・タグ、優先度、通知
- 複数のタブで同時に開いたときの同期（後から保存した内容が残る）
- 端末・ブラウザをまたいだ同期、ログイン
- TODO の件数の上限
