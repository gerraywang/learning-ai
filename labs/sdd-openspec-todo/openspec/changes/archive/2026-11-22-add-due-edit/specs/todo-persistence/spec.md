# Spec Delta

## MODIFIED Requirements

### Requirement: 操作のたびに保存する
システムは、保存領域が使える間、やることを変える操作（追加、完了の切り替え、削除、編集の確定（文言と期限））のたびに、やることの一覧全体を端末のブラウザの保存領域に保存する（SHALL）。再読み込みしたときは、保存した一覧を同じ順番・同じ内容で表示する。

#### Scenario: 再読み込みしても残る
- **GIVEN** 3 件を追加した
- **WHEN** 再読み込みする
- **THEN** 同じ 3 件が同じ順番で表示される

#### Scenario: 完了の状態が残る
- **GIVEN** やることを完了にした
- **WHEN** 再読み込みする
- **THEN** 完了のまま表示される

#### Scenario: 削除したものは戻らない
- **GIVEN** やることを削除した
- **WHEN** 再読み込みする
- **THEN** 削除したやることは表示されない

#### Scenario: 編集で変えた期限が残る
- **GIVEN** 編集で期限を外して確定した
- **WHEN** 再読み込みする
- **THEN** 期限なしのまま表示される
