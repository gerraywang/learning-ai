# Contract: 画面（UI）

**Date**: 2026-11-22 | 関連: [spec.md](../spec.md) の US1〜US5、FR-001〜FR-015

テスト（`tests/ui/app.test.js`）は、ここに書いたラベル・役割・文言で要素を探す。
見た目（色・配置）は自由だが、ここに書いた約束は変えない。変えるときは先に本書を直す（原則 IV）。

## 画面の要素

| 要素 | 種類 | ラベル／文言 | 関連 |
|---|---|---|---|
| 追加フォーム | `<form>` | — | US1, US4 |
| 文言の入力欄 | `<input type="text">` | ラベル「やること」 | FR-001 |
| 期限の入力欄 | `<input type="date">` | ラベル「期限（任意）」 | FR-008 |
| 追加ボタン | `<button type="submit">` | 「追加」 | FR-001 |
| 絞り込み | ボタン 3 つ（選択中は `aria-pressed="true"`） | 「すべて」「未完了」「完了」 | FR-011 |
| 一覧 | `<ul>` | ラベル「やることの一覧」 | FR-003 |
| 一覧の 1 行 | `<li>` | 下の表 | — |
| 空の表示 | 一覧の代わりに出す文 | 0 件:「やることはありません」／絞り込みで 0 件:「該当するやることはありません」 | FR-015 |
| お知らせ | `role="status"` の領域 | 下の表 | FR-002, FR-014 |

## 一覧の 1 行

| 部品 | 内容 | 関連 |
|---|---|---|
| 完了チェック | `<input type="checkbox">`、ラベルはやることの文言 | FR-005 |
| 文言 | 完了なら取り消し線（行に `done` クラス） | FR-006 |
| 期限 | 期限があれば「期限: YYYY-MM-DD」 | FR-009 |
| 期限切れの印 | 期限切れなら「期限切れ」の文字（行に `overdue` クラス） | FR-010 |
| 削除ボタン | 「削除」（読み上げ用の名前は「<文言> を削除」） | FR-007 |

- 各 `<li>` には `data-id="<Todo.id>"` を付ける。同じ文言のやることが複数あっても、
  行の中の部品（チェック・削除ボタン）はその行の中で探せば区別できる。

## 操作と結果

| 操作 | 結果 |
|---|---|
| 正しい文言で「追加」（Enter でも可） | 一覧の最後に未完了で追加。文言と期限の入力欄を空に戻す。お知らせを消す |
| 空・空白だけで「追加」 | 追加しない。お知らせ「やることを入力してください」 |
| 201 文字以上で「追加」 | 追加しない。入力は残す。お知らせ「200 文字以内で入力してください」 |
| チェックを付ける／外す | 完了／未完了を切り替え。選択中の絞り込みに合わなくなれば表示から外す |
| 「削除」 | 確認なしで削除 |
| 絞り込みボタン | 表示を切り替える。保存はしない |

## お知らせの文言

| 場面 | 文言 |
|---|---|
| 空の入力 | やることを入力してください |
| 200 文字超 | 200 文字以内で入力してください |
| 保存の失敗 | 保存できませんでした |
| 保存先が使えない | この端末に保存できません。閉じると内容は消えます |

- 「保存先が使えない」のお知らせが出ている間は、操作のたびの「保存できませんでした」は出さず、
  最初のお知らせを残す（同じ原因のお知らせを重ねて出さない）。
| 保存データが壊れている | 保存されたデータを読み込めませんでした |
