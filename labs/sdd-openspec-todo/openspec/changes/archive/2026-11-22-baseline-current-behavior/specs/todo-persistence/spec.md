# Spec Delta

## Purpose

やることを利用者の端末の中だけに保存し、閉じたり再読み込みしたりしても続きから使えるようにする。保存できないときは、そのことを利用者に知らせる。

## ADDED Requirements

### Requirement: 操作のたびに保存する
システムは、保存領域が使える間、やることを変える操作（追加、完了の切り替え、削除、文言の編集の確定）のたびに、やることの一覧全体を端末のブラウザの保存領域に保存する（SHALL）。再読み込みしたときは、保存した一覧を同じ順番・同じ内容で表示する。

#### Scenario: 再読み込みしても残る
- **GIVEN** 3 件を追加した
- **WHEN** 再読み込みする
- **THEN** 同じ 3 件が同じ順番で表示される

#### Scenario: 完了の状態が残る
- **GIVEN** やることを完了にした
- **WHEN** 再読み込みする
- **THEN** 完了のまま表示される

#### Scenario: 削除したものは戻らない
- **GIVEN** やることを削除した
- **WHEN** 再読み込みする
- **THEN** 削除したやることは表示されない

### Requirement: 保存したデータとの互換
システムは、保存領域のキー `sdd-speckit-todo` に、版 1 の形式（各やることの id・文言・完了の状態・期限）で保存し、同じ形式のデータを読み込めなければならない（MUST）。

#### Scenario: 既存の保存データを読み込む
- **GIVEN** キー `sdd-speckit-todo` に版 1 の形式で 2 件が保存されている
- **WHEN** アプリを開く
- **THEN** その 2 件が保存された順番で表示される

### Requirement: 保存に失敗したときに知らせる
システムは、保存に失敗したとき、操作の結果は画面に反映したうえで「保存できませんでした」と知らせる（SHALL）。

#### Scenario: 追加の保存に失敗する
- **GIVEN** 保存領域への書き込みが失敗する
- **WHEN** やることを追加する
- **THEN** 画面には追加され、「保存できませんでした」と表示される

#### Scenario: 編集の確定の保存に失敗する
- **GIVEN** 保存領域への書き込みが失敗する
- **WHEN** 文言の編集を確定する
- **THEN** 画面には新しい文言が表示され、「保存できませんでした」と表示される

### Requirement: 保存領域が使えないときに知らせる
システムは、開いたときに保存領域が使えない（設定で禁止されているなど）とき、「この端末に保存できません。閉じると内容は消えます」と表示し、そのお知らせを残したまま操作を続けられるようにする（SHALL）。この間は保存を試みない。

#### Scenario: 保存領域が使えない
- **GIVEN** 保存領域にアクセスできない
- **WHEN** アプリを開いて、やることを追加する
- **THEN** 追加でき、「この端末に保存できません。閉じると内容は消えます」が表示されたまま残る

### Requirement: 保存データが壊れているときに知らせる
システムは、開いたときに保存データが読めない（形式が違う、決まりに合わないやることを含むなど）とき、空の一覧で始め、「保存されたデータを読み込めませんでした」と知らせる（SHALL）。読み込むときに壊れたデータを消すことはしない。

#### Scenario: 壊れたデータで開く
- **GIVEN** 保存データが壊れている
- **WHEN** アプリを開く
- **THEN** 空の一覧で始まり、「保存されたデータを読み込めませんでした」と表示される

#### Scenario: 読み込むだけでは消さない
- **GIVEN** 保存データが壊れている
- **WHEN** アプリを開く（まだ何も操作しない）
- **THEN** 保存領域の壊れたデータはそのまま残っている

### Requirement: 端末の外に送らない
システムは、やることのデータを端末の外（サーバーなど）に送らない（SHALL）。外部と通信する仕組みを使わない。

#### Scenario: 通信しない
- **WHEN** どの操作をしても
- **THEN** やることのデータは端末の外に送られない
