# Spec Delta

## Purpose

一覧に追加したやることの文言を、その行の中で直したり、直すのをやめて元に戻したりするための操作を定める。

## ADDED Requirements

### Requirement: 文言の編集を始める
システムは、各やることの「編集」ボタンで、その行をいまの文言が入った入力欄と「確定」「取り消し」ボタンに切り替える（SHALL）。「編集」ボタンは「削除」ボタンの前に置き、読み上げ名は「<文言> を編集」とする。編集を始めると入力欄にフォーカスを移し、出ていたお知らせを消す。

#### Scenario: 編集を始める
- **WHEN** 「牛乳を買う」の「編集」を押す
- **THEN** その行に「牛乳を買う」が入った入力欄が出て、入力欄にフォーカスがある

#### Scenario: 編集中の行にも期限を表示する
- **GIVEN** 期限付きのやることがある
- **WHEN** その行の編集を始める
- **THEN** 編集中の行にも期限（と、期限切れならその印）が表示される

### Requirement: 編集中は 1 行だけ
システムは、編集中の行を常に 1 行までにする（SHALL）。編集中に別の行の編集を始めると、前の行は確定せずに元の文言に戻し、新しい行を編集中にする。

#### Scenario: 別の行の編集を始める
- **GIVEN** 「牛乳を買う」を「豆乳を買う」に書き換えている途中
- **WHEN** 「本を返す」の「編集」を押す
- **THEN** 「牛乳を買う」は元の文言のまま通常の行に戻り、「本を返す」だけが編集中になる

### Requirement: 文言の編集を確定する
システムは、「確定」ボタンまたは入力欄での Enter で、入力した文言の前後の空白を除いてやることの文言を置き換え、通常の行に戻す（SHALL）。確定したら、その行の「編集」ボタンにフォーカスを移す。

#### Scenario: 書き換えて確定する
- **WHEN** 「牛乳を買う」を「豆乳を買う」に書き換えて「確定」を押す
- **THEN** 文言が「豆乳を買う」になり、編集中の状態が終わる

#### Scenario: Enter で確定する
- **WHEN** 書き換えて入力欄で Enter を押す
- **THEN** 「確定」を押したときと同じく確定する

#### Scenario: 前後の空白を除いて確定する
- **WHEN** 「  豆乳を買う  」と書き換えて確定する
- **THEN** 文言は「豆乳を買う」になる

#### Scenario: 変えずに確定する
- **WHEN** 文言を変えずに（または前後の空白だけを足して）確定する
- **THEN** エラーにならず、同じ文言のまま通常の行に戻る

### Requirement: 文言の編集では文言だけを変える
システムは、文言の編集を確定しても、そのやることの完了の状態・期限・一覧の中の位置を変えない（SHALL）。ほかのやることも変えない。期限を編集する手段はない。

#### Scenario: 期限付き・未完了のやることを編集する
- **GIVEN** 期限が 2026-12-01 で未完了のやることがある
- **WHEN** その文言を編集して確定する
- **THEN** 文言だけが変わり、期限は 2026-12-01、状態は未完了のまま

#### Scenario: 完了のやることを編集する
- **WHEN** 完了のやることの文言を編集して確定する
- **THEN** 文言だけが変わり、完了のまま

#### Scenario: 位置は変わらない
- **GIVEN** 3 件ある
- **WHEN** 2 件目の文言を編集して確定する
- **THEN** 2 件目の位置のまま文言が変わる

#### Scenario: 同じ文言の行が複数ある
- **GIVEN** 同じ文言のやることが 2 件ある
- **WHEN** 片方の文言を編集して確定する
- **THEN** 編集した行だけが変わる

### Requirement: 決まりに合わない文言では確定しない
システムは、確定しようとした文言が文言の決まり（前後の空白を除いて 1〜200 文字）に合わないとき、文言を変えず、編集中のまま入力を残し、理由を知らせる（SHALL）。お知らせの文言は追加のときと同じとし、入力欄にフォーカスを戻す。そのあとも、直して確定することも取り消すこともできる。

#### Scenario: 空にして確定しようとする
- **WHEN** 入力欄を空にして、または空白だけにして確定しようとする
- **THEN** 文言は変わらず、編集中のまま入力が残り、「やることを入力してください」と表示される

#### Scenario: 201 文字で確定しようとする
- **WHEN** 201 文字にして確定しようとする
- **THEN** 編集中のまま 201 文字が残り、「200 文字以内で入力してください」と表示される

#### Scenario: ちょうど 200 文字は確定できる
- **WHEN** ちょうど 200 文字にして確定する
- **THEN** その文言に変わる

#### Scenario: 確定できなかったあとに直して確定する
- **GIVEN** 空の文言で確定できなかった
- **WHEN** 正しい文言に直して確定する
- **THEN** その文言に変わる

### Requirement: 文言の編集を取り消す
システムは、次のどれかで編集を取り消し、元の文言のまま通常の行に戻す（SHALL）。「取り消し」ボタン、Esc キー、編集中の行の外のクリック、ほかの操作（完了の切り替え、追加、削除、絞り込みの切り替え、別の行の編集の開始）。ほかの操作で取り消したときは、その操作も通常どおり行う。取り消しは保存しない。

#### Scenario: 「取り消し」で元に戻す
- **WHEN** 書き換えてから「取り消し」を押す
- **THEN** 元の文言のまま編集中の状態が終わり、その行の「編集」にフォーカスがある

#### Scenario: Esc で元に戻す
- **WHEN** 書き換えてから Esc を押す
- **THEN** 「取り消し」を押したときと同じく取り消される

#### Scenario: 日本語の変換中の Esc では取り消さない
- **WHEN** 日本語の変換中に Esc を押す
- **THEN** 編集中のまま、入力も残る

#### Scenario: 行の外をクリックする
- **WHEN** 編集中に見出しなど行の外をクリックする
- **THEN** 元の文言のまま編集中の状態が終わる

#### Scenario: 行の中をクリックしても取り消さない
- **WHEN** 編集中の行の入力欄や期限の表示をクリックする
- **THEN** 編集中のまま

#### Scenario: 別のやることの完了を切り替える
- **GIVEN** 「牛乳を買う」を書き換えている途中
- **WHEN** 「本を返す」の完了を切り替える
- **THEN** 「牛乳を買う」は元の文言のまま編集が終わり、「本を返す」は完了になって保存される

#### Scenario: 取り消したあとにもう一度編集する
- **GIVEN** 書き換えてから取り消した
- **WHEN** 同じ行の編集をもう一度始める
- **THEN** 入力欄には元の文言が入っている

#### Scenario: 確定できなかった理由のお知らせを消す
- **GIVEN** 空の文言で確定できず、お知らせが出ている
- **WHEN** 「取り消し」または行の外のクリックで取り消す
- **THEN** お知らせが消える

### Requirement: 編集中の状態は保存しない
システムは、編集中であること自体と書きかけの文言を保存しない（SHALL）。確定した文言だけを保存する。

#### Scenario: 確定した文言は残る
- **WHEN** 文言を確定してから再読み込みする
- **THEN** 確定した文言が表示される

#### Scenario: 編集中に再読み込みする
- **GIVEN** 書き換えている途中
- **WHEN** 再読み込みする
- **THEN** 元の文言で表示され、編集中の行はない
