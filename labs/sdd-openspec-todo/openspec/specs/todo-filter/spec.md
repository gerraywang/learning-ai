# todo-filter Specification

## Purpose

一覧を完了の状態で絞り込み、いま見たいやることだけを表示できるようにする。

## Requirements

### Requirement: 状態で絞り込む
システムは、「すべて」「未完了」「完了」の 3 つのボタンで一覧の表示を切り替える（SHALL）。絞り込んでも、やることの順番は変えない。選んでいるボタンは押された状態として示す。

#### Scenario: 未完了だけを表示する
- **GIVEN** 未完了 2 件、完了 1 件がある
- **WHEN** 「未完了」を選ぶ
- **THEN** 未完了の 2 件だけが元の順番で表示される

#### Scenario: 完了だけを表示する
- **GIVEN** 未完了 2 件、完了 1 件がある
- **WHEN** 「完了」を選ぶ
- **THEN** 完了の 1 件だけが表示される

#### Scenario: すべてを表示する
- **GIVEN** 「未完了」を選んでいる
- **WHEN** 「すべて」を選ぶ
- **THEN** 3 件すべてが表示される

#### Scenario: 状態が変わるとすぐ表示から外れる
- **GIVEN** 「未完了」を選んでいる
- **WHEN** 表示中のやることを完了にする
- **THEN** そのやることはすぐ表示から外れる

### Requirement: 絞り込みは保存しない
システムは、選んだ絞り込みを保存しない（SHALL）。開いたときと再読み込みしたときは、常に「すべて」を選んだ状態で始める。

#### Scenario: 初めて開く
- **WHEN** アプリを開く
- **THEN** 「すべて」が選ばれている

#### Scenario: 再読み込みで「すべて」に戻る
- **GIVEN** 「未完了」を選んでいる
- **WHEN** 再読み込みする
- **THEN** 「すべて」が選ばれている

### Requirement: 絞り込みで 0 件のときの表示
システムは、絞り込みで表示するやることが 0 件になったとき、「該当するやることはありません」と表示する（SHALL）。ただし、やることが全体で 0 件のときは、絞り込み中でも「やることはありません」と表示する。

#### Scenario: 該当が 0 件
- **GIVEN** やることがあり、すべて未完了
- **WHEN** 「完了」を選ぶ
- **THEN** 「該当するやることはありません」と表示される

#### Scenario: 全体が 0 件
- **GIVEN** やることが 1 件もない
- **WHEN** 「未完了」を選ぶ
- **THEN** 「やることはありません」と表示される
